# Lasuarindo Group Website

Company profile website for PT Lasuarindo Group, an integrated business and investment group. Visitors can read about the group's businesses, the T46 ecosystem and its units, licensing, partnership, and contact details. The site is available in Indonesian and English.

## Tech stack

The UI is built with React 19 and React Router 7. Vite 8 handles development and builds, using Rolldown for bundling, and Tailwind CSS 4 handles styling. Content is translated with i18next and react-i18next; Oxlint checks the code, and Rspress v2 builds the project documentation.

## Packages

For animation and interaction the site uses `motion`, `embla-carousel-react`, `react-countup`, and `react-fast-marquee`. Icons come from `lucide-react` and `@tabler/icons-react`, and `rspress-plugin-mermaid` draws diagrams in the docs.
