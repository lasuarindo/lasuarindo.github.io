# Conventions

A few rules keep this documentation consistent and trustworthy.

## Two languages

The website is published in Indonesian and English. Translated copy is kept in matching pairs, one file for each language. A change to one language should be made in the other as well. A check runs before every build to make sure the two sides still match.

## Names and facts

Proper names, such as a person's name or a product name, are not translated. Numbers and company details come from project data, not from guesswork. If a value has not been confirmed, it is left out or marked draft.

## Draft markers

Draft is a status, not a style choice. It tells readers that a section is still being prepared. Do not remove a draft marker until the information is confirmed.

## Where to write

- Simple explanation for visitors → [For Everyone](/for-everyone/)
- Page explanation with technical notes → [Pages](/pages/)
- Code and configuration → [Docs](/docs/)
- What changed → [Changelog](/changelog/)
