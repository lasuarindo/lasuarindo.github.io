# Navigation

This site is split into sections. Each section has its own sidebar so the links you see belong to what you are reading.

## Top navigation

The top bar lists the sections in this order: Guide, For Everyone, Docs, Pages, Changelog and GitHub. Choosing a section takes you to its starting page. GitHub opens the Lasuarindo organisation. The home page opens from the logo.

## Sidebars

- **Guide** explains how to read and use this documentation site.
- **For Everyone** explains the website in everyday language.
- **Docs** holds the technical project documentation.
- **Pages** describes each website page, with both plain and technical notes.
- **Changelog** records what changed.
- **GitHub** opens the Lasuarindo organisation repository.

Sidebar groups are plain section headers. Items sit at the same level as their header, and the current page is highlighted so you can see where you are.

## Moving between sections

Use the top bar to change section. Use the sidebar to stay within one. If a page links to another section, the link will open that section's own navigation.
