This section explains every page of the Lasuarindo Group website. Each page starts with a plain explanation, then ends with a "For maintainers" part containing technical details. If you want a version without any technical detail, use the [For Everyone](/for-everyone/) section instead.

## How to use this section

Open a page above to see what a visitor can find there, where the page links to, and anything worth knowing before you write or change its content. Read the first part for the simple explanation and the "For maintainers" part for the route, copy bundle, data and behaviour. For a version with no technical detail, use [For Everyone](/for-everyone/). For code and configuration, use the [Project Documentation](/docs/) section.

## A note on draft labels

Some parts of the website are marked draft. That means the information is still being prepared and should not be treated as final. The labels are there to help readers tell the difference between confirmed facts and illustrative content.
