# Docs Guide

This section explains the documentation site itself: how it is built, navigated and maintained. The [Docs](/docs/) section explains the application instead. You do not need any technical background to read this part.

## The sections

| Section | For whom | What it contains |
|---|---|---|
| For Everyone | General visitors | The website explained in everyday language |
| Docs | Developers and designers | Technical project documentation |
| Pages | Writers and maintainers | Every page, with plain notes and technical notes together |
| Changelog | Everyone | What changed and when |

The Docs Guide is a group in the Docs sidebar, so open the Docs section to reach these pages. The home page opens from the logo in the top bar. The GitHub icon opens the Lasuarindo organisation; it is a link, not a section.

## Suggested reading paths

- **Learn the docs guide:** start here, then open [Rspress setup](/docs/guide-setup) and [Contributing](/docs/guide-contributing).
- **Understand the website:** start with [For Everyone](/for-everyone/), then open [Pages](/pages/).
- **Work on the code:** start with [Docs](/docs/), then open [Pages](/pages/).
- **See what shipped:** go to [Changelog](/changelog/).

## How navigation works

Each section has its own sidebar. Use the top bar to change section and the sidebar to move inside it. See [Contributing](/docs/guide-contributing#top-navigation) for how groups work.
